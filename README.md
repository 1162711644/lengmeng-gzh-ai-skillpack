## 简介

由 Coze 技能导出的公众号创作工作流修复而来的**自包含版本**：不依赖任何私有脚本或私有 API，安装即可用。

整合 7 大核心能力，覆盖公众号创作者从选题、标题、爆款分析、封面设计到文案撰写的完整链路：

| # | 功能 | 说明 |
|---|------|------|
| 1 | 爆款标题生成与评分 | 基于爆款特征分析生成 10 个标题，四维度 100 分制评分 |
| 2 | 10w+ 热门文章 | 按 23 分类检索近期 10w+ 爆文并输出规律分析 |
| 3 | 文章搜索与趋势分析 | 公众号文章检索、15 分制评分、近 30 天选题热度趋势 |
| 4 | 爆款封面生成 | 7 维度封面分析 + 3 套设计方案 + AI 出图（2.35:1） |
| 5 | 文案创作 | 差异化优势拆解 + 爆款规律对照，1500 字完整文案 |
| 6 | 阅读增长榜 | 公开榜单检索 + 爆文/作品类型分析 |
| 7 | 综合实力榜 | 日/周/月榜查询，TOP50 格式化表格输出 |

## 快速安装

### 豆包 / WorkBuddy

把 `SKILL.md` 放入目标平台的技能目录，例如：

```text
<skills根目录>/gzh-creator-suite/SKILL.md
```

重启会话后即可通过自然语言触发。

### Coze（扣子）

在 Bot 的技能设置中新建技能，将本仓库 `SKILL.md` 内容整体粘贴保存。

### 通用

任意支持 `SKILL.md` 规范的 Agent 平台均可使用，放置到对应 skills 目录即可。

## 与原版（Coze 导出版）的关系

原版依赖 Coze 私有数据脚本（`scripts/` 与 `references/` 未随导出携带），安装后无法运行。本仓库为**自包含修复版**：

- 数据获取：通过 Agent 公开检索（general_search / web_fetch）并附来源，检索不到时如实说明并改用爆款规律分析，不编造数据；
- 创意生成：标题、文案、封面设计方案与出图均由 Agent 直接完成；
- 若后续获得原版脚本，可放回 `scripts/` 目录并切换回脚本调用模式。
